Turing Machine

Turing Machines are deterministic:

  • Partial transition allowed
  • ε\varepsilonε-transitions not allowed

A string is rejected if machine halts in a non-accept state or if machine enters an infinite loop

Pumping

Pumping Lemma for Regular Languages

Given an infinite regular language LLL, there exists an integer ppp, for any string w∈Lw \in Lw∈L with length ∣w∣≥p|w| \ge p∣w∣≥p, we can write

w=xyz,∣xy∣≤p,∣y∣≥1w = xyz, \quad |xy| \leq p, \quad |y| \ge 1 w=xyz,∣xy∣≤p,∣y∣≥1

such that:

xyiz∈L,∀i≥0xy^iz \in L, \forall i \geq 0 xyiz∈L,∀i≥0

ppp: critical length

Pumping lemma also holds for finite language. Just set p = M+1, where M denotes the max length of strings in L.

Pumping Lemma for Context-Free Languages

For any infinite context-free language LLL, there exists an integer ppp such that for any string w∈Lw \in Lw∈L with length ∣w∣≥p|w| \ge p∣w∣≥p, we can write

w=uvxyz,∣vxy∣≤p,∣vy∣≥1w = uvxyz, \quad |vxy| \leq p, \quad |vy| \ge 1 w=uvxyz,∣vxy∣≤p,∣vy∣≥1

such that:

uvixyiz∈L,∀i≥0uv^ixy^iz \in L, \forall i \geq 0 uvixyiz∈L,∀i≥0

ppp: magic number

Max string length without a repeated state from root to leaf: trt^rtr
r: number of variables
t: max right-hand size of any production
